# shipnet

Ship color net values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/shipnet/

## Install / run

```bash
git clone https://github.com/theworker02/shipnet.git
cd shipnet
node src/cli.js
node --test
```
